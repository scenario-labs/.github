# scenario-labs/.github

Public defaults for the [scenario-labs](https://github.com/scenario-labs) organization.

| File                                                                                                                                       | Role                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [`profile/README.md`](profile/README.md)                                                                                                   | The org page everyone sees on github.com/scenario-labs. Keep it short: it is advertising.       |
| [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Defaults for every repository that has no file of its own. A repository's own file always wins. |

Everything here is public. Members-only content belongs in [`.github-private`](https://github.com/scenario-labs/.github-private).

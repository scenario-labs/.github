# Contributing

Thanks for helping. Each repository's own `CONTRIBUTING.md` or `AGENTS.md`, when
present, takes precedence over this page.

- **Open an issue first** for anything beyond a typo, so we agree on the scope
  before you write code.
- **Fork, branch, pull request.** One concern per pull request. Titles follow
  [Conventional Commits](https://www.conventionalcommits.org): `fix(scope): summary`.
- **Keep it public-safe.** Issues, pull requests and commits are public and
  permanent: no credentials, signed URLs, account or project ids, or private data.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities through
  [SECURITY.md](SECURITY.md), never in a public issue.
